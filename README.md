# toolbox
收录了我在学习过程中编写的各类实用工具、仿真脚本以及桌面软件，也包括一些尝试，目前还在不断整理完善。

## 📂 目录导航

### 1. [C++ 工具集 (cpp-tools)](./cpp-tools)
包含基于 C++ 编写的数据处理工具。

### 2. [MATLAB 工具集 (matlab-tools)](./matlab-tools)
包含用于工程计算、数据可视化以及 App Designer 开发的工具。

### 3. [个人主页管理工具 (profilemanagement)](./profilemanagement)
一个基于 Python 开发的桌面级图形化工具。
*   **功能**：可视化拖拽管理 GitHub Pages 个人主页的作品卡片，内置本地实时预览、目录监控，并支持一键生成 HTML 并自动推送至 GitHub。

---

## 🛠️ 通用环境说明
*   C++ 工具建议使用 Visual Studio 编译。
*   MATLAB 工具需在 MATLAB 2024b 及以上版本运行。
*   Python 工具需 Python 3.8+，请参考各子文件夹下的 `requirements.txt`。
