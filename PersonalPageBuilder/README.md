# Personal Page Builder

一个在自己电脑上用的「个人主页可视化编辑器」：左边是素材库，右边是卡片编辑器，中间可以和真实网页一样的预览窗。
编辑完点一下【同步到 index.html】，它会帮你把图片视频放进仓库、改写页面、提交并推送到 GitHub。

不用写 HTML，也不用记 git 命令。代码里没有任何人的私人路径、账号或密钥 —— 所有目录都由你自己指定。

---

## 1. 它能做什么

1. 扫描你指定的素材文件夹，把图片 / 视频做成缩略图列在左边（视频用 ffmpeg 抽首帧）
2. 点一下或拖一下素材，就在右边的栏目里生成一张卡片，标题和描述随打随改
3. 一个页面可以有多个栏目，每个栏目独立选择排版：网格 / 横向滑动 / 列表
4. 右侧打开实时预览窗：直接在网页上改文字、拖动卡片换顺序，改完立刻反映到编辑器
5. 同步时自动压缩图片（默认 WebP，长边 1600），同样的内容体积通常只剩十分之一，访客打开更快
6. 一键 git add / commit / push，GitHub Pages 一两分钟后自动更新

---

## 2. 准备工作

| 需要 | 说明 |
| --- | --- |
| Python 3.8+ | Windows 建议用 [python.org](https://www.python.org/downloads/) 的安装包，勾选 Add to PATH；要有 tkinter（官方包自带） |
| Git | 已经配置好提交身份和 GitHub 凭据（能手动 `git push` 就行） |
| GitHub 仓库 | 建议是 `<用户名>.github.io` 这种 GitHub Pages 仓库，并且已经 clone 到本地 |
| ffmpeg（可选） | 只有视频首帧缩略图需要；没有也能用，视频卡片显示占位图 |

依赖会在第一次启动时由启动脚本自动安装（Pillow / pywebview / watchdog），也可以提前手动装：

```bash
python -m pip install -r requirements.txt
```

## 3. 启动

- Windows：双击 `run.bat`
- macOS / Linux：`bash run.sh`（或先 `chmod +x run.sh`）

**第一次启动会先弹出「隐私与数据安全声明」**，需要点【同意并继续】才会往下走；
点【不同意，退出】或直接关窗口，程序就退出，不会动你的任何文件。
确认记录存在数据目录的 `privacy.json`（只记版本号和时间），以后不再打扰；
想重新看，在设置窗里点【隐私声明】。声明有实质性修改时版本号会加一，届时会再问一次。

确认之后弹出设置窗，必须填两项：

1. **素材目录**：放图片、视频的文件夹，程序只读这里，不会移动或删除你的文件
2. **仓库目录**：本地 git 仓库的根目录（`git clone` 出来的那一层），同步会写这里并推送

其余几项一般不用改：

- **页面文件**：默认 `index.html`，可以填 `pages/works.html` 之类
- **远端名**：默认 `origin`
- **分支**：留空表示推送到当前分支在远端的同名分支；填 `main` 就强制推 `main`
- **ffmpeg**：可选，留空则从 PATH 里找

填完可以点【检查目录】先看看有没有问题，再点保存。

### 页面要先有两个标记

程序不会重写整张网页，只替换这两个注释之间的内容：

```html
<!-- PORTFOLIO_START -->
<!-- PORTFOLIO_END -->
```

如果你的 `index.html` 里还没有，保存设置时会问你要不要自动插入（插在 `</body>` 前，原文件备份成 `index.html.bak`）。
也可以自己手动放到想展示作品的位置，例如：

```html
<h2>项目经历</h2>

<!-- PORTFOLIO_START -->
<!-- PORTFOLIO_END -->
```

## 4. 日常使用

1. 左边点素材 → 右边出现卡片；也可以直接拖到某个栏目的卡片区
2. 改标题、描述；用栏目头的下拉切换排版，`↑ ↓` 调整栏目顺序
3. 右侧预览窗里：点文字直接改，按住卡片左上角的小圆点可以拖动换位置或换栏目
4. 点【同步到 index.html】→ 确认 → 等日志走完（复制素材 → 替换页面 → commit → push）
5. 一两分钟后刷新你的 GitHub Pages 网址就能看到

同步时显示「仓库没有变化，跳过提交」是正常的：说明这次内容和上次一样。

## 5. 图片压缩

顶栏按钮显示当前策略（例如「图片压缩：WEBP·1600px」），点开可调：

- **输出格式**：WebP（体积最小）/ JPEG（兼容性最好）
- **长边上限**：1280 / 1600 / 1920 / 2560 / 保持原尺寸
- **压缩质量**：60–95，默认 82
- **测算当前素材**：先不写仓库，只算一下能省多少

几个行为说明：

1. 只压「要上传的那一份」，素材目录里的原图不动
2. 压缩后文件名会变（`a.png` → `a.webp`），页面引用会自动跟着改
3. 结果缓存在本机，改参数才会重压；重复同步不会重复处理
4. 动图不压（避免丢帧）；透明图转 JPEG 会自动补白底；压完反而更大的会回退原图

## 6. 数据与隐私

完整的隐私与数据安全声明见 **[PRIVACY.md](PRIVACY.md)**（含「会写哪些文件」的完整清单）。这里只列要点：

- 配置、存档、改前备份、缓存都在 **`~/.personal_page_builder/`**（Windows 是 `C:\Users\<你>\.personal_page_builder`），不在程序目录，也不进你的 git 仓库
- `config.json` 里只有你自己填的本机路径、远端名和分支，不会上传到任何地方
- 每个仓库的编辑进度分开保存（`repos/<仓库指纹>/state.json`），换仓库不会串
- 想放到别处（比如 U 盘随身带）：设置环境变量 `PPB_DATA_DIR` 指向目标目录即可
- 程序不写注册表、不写系统目录、不装服务、不设开机启动；删除数据目录即彻底清除
- 无遥测、无账号、不自动联网；唯一的网络行为是**你主动点同步时**由本机 git 推送，以及预览窗口在 `127.0.0.1` 的随机端口上跑本地服务
- 预览端口只接受本机 Host，拒绝 `.git` / `.env` / `.ssh` 等敏感路径与目录越界访问，别的网页无法借道读取你的文件
- 所有 JSON 保存都「内容没变就不写」，且先写临时文件再整体替换，断电不会写坏配置

目录大致长这样：

```
~/.personal_page_builder/
├── config.json          # 你填的目录与远端
├── settings.json        # 图片压缩偏好
├── repos/<指纹>/        # 各仓库的编辑存档
│   ├── state.json
│   └── backup/          # 改页面文字 / 插标记前的原文件备份
└── cache/               # 视频首帧、压缩结果、预览页缓存（可随时删）
```

## 7. 常见问题

**同步失败：请确认仓库目录是一个 git 仓库**
仓库目录选错了层级，或者根本没有 `git clone`。选含 `.git` 的那一层。

**git push 失败 / 需要认证**
先在终端里手动 `git push` 一次完成登录（或用 Personal Access Token / SSH key）。程序运行时不会弹密码框，认证不通就会直接报错。

**提示仓库里没有名为 origin 的远端**
在设置里把「远端名」改成实际的名字，或执行 `git remote add origin <仓库地址>`。

**页面没变化**
确认标记 `<!-- PORTFOLIO_START -->` / `<!-- PORTFOLIO_END -->` 存在并且在你希望出现的位置；同步日志里会写「index.html 已更新（xxxx 字节）」。

**视频卡片没有缩略图**
装 ffmpeg 并在设置里填路径，或把它加入 PATH。

**想撤销某次改动**
每个仓库的改前备份在 `~/.personal_page_builder/repos/<指纹>/backup/`，复制回去即可。

**换电脑 / 换仓库**
换仓库：顶栏【⚙ 设置】里改目录，保存即可，互不影响。
换电脑：重新运行、重新选目录就行；旧机器上的存档不会跟着走（也不含隐私上传）。

## 8. 文件说明

```
PersonalPageBuilder/
├── personal_page_builder.py   # 主程序（tkinter 界面 + HTML 生成 + git 同步）
├── ppb_preview.py             # 实时预览子进程（本地 HTTP + pywebview 窗口）
├── requirements.txt           # Python 依赖
├── run.bat                    # Windows 启动脚本
├── run.sh                     # macOS / Linux 启动脚本
├── PRIVACY.md                 # 隐私与数据安全声明（写入清单、网络行为、权限）
└── README.md
```

删除整个文件夹即可卸载；如果也想清掉配置，再删 `~/.personal_page_builder`。
